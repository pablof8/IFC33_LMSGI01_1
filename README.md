# Tasca LMSGI01.1 - Llenguatges de marques

Arxius de la primera tasca del mòdul IFC33_LMSGI (DAW).

## Contingut

- `exercici_1_1.xml`: agenda de contactes, primer fragment corregit.
- `exercici_1_2.xml`: horari de classes, segon fragment corregit.
- `exercici_2.xml`: catàleg de pel·lícules.
- `exercici_3.xml`: torneig de pàdel convertit de JSON a XML.
- `exercici_4.xml`: inventari de plantes actualitzat.
- `exercici_5.json`: dues enquestes amb preguntes i opcions.

Els documents XML utilitzen la codificació UTF-8 i es poden obrir amb un editor de text com Visual Studio Code. El fitxer JSON també es pot obrir i comprovar amb VS Code.

Per comprovar la sintaxi: obre els arxius en VS Code amb un validador XML (per exemple, l'extensió XML de Red Hat) i revisa els avisos de l'editor; el suport JSON és integrat. XML i JSON són formats de dades: no són aplicacions executables.
